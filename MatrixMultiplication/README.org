* Matrix Multiplication

This example implements square matrix multiplication on the GPU using CUDA, comparing a naive implementation with an optimised version using shared memory. Each GPU thread computes a single element of the output matrix by calculating the dot product of a row from the first matrix and a column from the second matrix.

It demonstrates several fundamental CUDA concepts:
- Allocating device memory and transferring data between the host and GPU;
- Configuring CUDA thread blocks and grids to cover a two-dimensional matrix;
- Using thread and block indices to map GPU threads to matrix elements;
- Implementing naive matrix multiplication, where each thread reads directly from global memory;
- Using shared memory to cache matrix tiles and reduce global memory accesses;
- Synchronising threads within a block using ~__syncthreads()~;
- Measuring kernel execution time and comparing the performance of both implementations;
- Verifying the results against the expected matrix product.
